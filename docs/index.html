Install it in a minute

Easiest: in VS Code open Extensions, search Agent Standup, click Install (Marketplace). Or by hand:

  1. Download the .vsix file above.
  2. In VS Code: Extensions → the … menu → Install from VSIX… and pick the file.
  3. Reload, click the camera icon in the sidebar, press Join. That’s it.

You need VS Code 1.80+ and to have used Claude Code on this machine at least once. Voices are best on a Mac.

What you actually get

  • A live call that follows your Claude Code session.
  • Sub-agents join, share their screen, leave.
  • Voices.
  • Tokens per agent.
  • A tree, a timeline, a recap.
  • Replay.
  • Office music.
